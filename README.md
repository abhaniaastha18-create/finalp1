##What is Data Analysis?
**Data analysis is the process of collecting, cleaning, organizing, examining, and visualizing data to find useful information, identify patterns, and make better decisions.
**Example: In the Titanic Survival Analysis project, we analyze passenger age, gender, ticket class, and survival status to understand which factors were associated with survival.
##2. Steps of Data Analysis

##Step 1: Data Collection
Collect data from CSV files, Excel files, databases, websites, or surveys.
Example: Download the Titanic dataset.


##Step 2: Data Cleaning
Remove duplicates, handle missing values, and correct errors.
Example: Fill missing passenger ages.


##Step 3: Data Preparation
Select useful columns, change data types, and organize the dataset.


##Step 4: Exploratory Data Analysis (EDA)
Calculate averages, counts, percentages, and correlations to understand the data.


##Step 5: Data Visualization
Create bar charts, line charts, histograms, and heatmaps to show patterns.


##Step 6: Interpretation and Reporting
Explain the results, draw conclusions, and communicate findings.


##3. Methods of Data Analysis
There are four main types of data analysis.

**1. Descriptive Analysis
Explains what happened using counts, averages, percentages, and summaries.
Example: Calculate how many Titanic passengers survived.


**2. Diagnostic Analysis
Investigates why something happened by comparing groups and examining relationships.
Example: Investigate differences in survival rates between passenger classes.**


**3. Predictive Analysis
Uses statistical models or machine learning to estimate future or unknown outcomes.
Example: Build a model to predict passenger survival from available features.


**4. Prescriptive Analysis
Recommends actions based on data, objectives, and constraints.
Example: Recommend how an organization could allocate resources to reduce risk.

##5. Important concepts in Data Analysis
*- Dataset: A collection of related data.
*- Rows: Individual records, such as passengers.
*- Columns: Features or attributes, such as age and gender.
*- Mean: Average value.
*- Median: Middle value when data is ordered.
*- Mode: Most frequently occurring value.
*- Missing values: Data that is not available.
*- Outliers: Values that differ substantially from most observations.
*- Correlation: A measure of how two variables change together.
*- Visualization: Presenting data in charts or graphs.
